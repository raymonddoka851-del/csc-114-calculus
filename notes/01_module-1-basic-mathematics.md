# 01 · Module 1 — Basic Mathematics

> Source: Calculus Module 2. Use these number and algebra foundations before moving to functions and calculus.

## Number sets

- **Natural numbers:** 0, 1, 2, 3, … (some conventions start at 1; follow the course convention).
- **Integers:** …, −2, −1, 0, 1, 2, …
- **Rational numbers:** numbers expressible as a/b, where a and b are integers and b ≠ 0. A fraction is in lowest terms when numerator and denominator have no common factor except 1.
- **Irrational numbers:** real numbers that cannot be written as a ratio of integers, such as √2 and π.

Every terminating decimal is rational: 1.4 = 14/10 = 7/5. A repeating decimal is rational too.

## Operations and powers

Addition and multiplication are commutative and associative; multiplication distributes over addition:

- a + b = b + a; (a + b) + c = a + (b + c)
- ab = ba; (ab)c = a(bc)
- a(b + c) = ab + ac
- a + (−a) = 0; a × (−1) = −a

For integer exponents (when the expressions are defined):

- aᵐ × aⁿ = aᵐ⁺ⁿ
- (aᵐ)ⁿ = aᵐⁿ
- (ab)ⁿ = aⁿbⁿ
- a⁰ = 1 for a ≠ 0; a⁻ⁿ = 1/aⁿ for a ≠ 0

**Parity:** an even integer has form 2k; an odd integer has form 2k + 1. Even + even and odd + odd are even; even + odd is odd.

## Common errors

- Dividing by zero is undefined; a fraction’s denominator must be nonzero.
- (a + b)² is not a² + b²: expand it as a² + 2ab + b².
- A negative exponent means reciprocal, not a negative value: 2⁻³ = 1/8.
